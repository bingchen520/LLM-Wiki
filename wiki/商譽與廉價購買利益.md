# 商譽與廉價購買利益（Goodwill / Bargain Purchase Gain）
> 買一家公司付的錢，**超過**它「看得到的淨資產」公允價值的部分就是**商譽**（買的是品牌、客戶、團隊等看不到的價值）；如果付的比較少，就是撿到便宜：**廉價購買利益**。

## 定義
- **商譽**：被收購者之權益依 IFRS 3 衡量之金額，超過其可辨認淨資產公允價值的部分。[Ch1 p.6]
- **廉價購買利益**：被收購者可辨認淨資產公允價值大於其權益依 IFRS 3 衡量之金額，經**重新評估及覆核**後仍然較大，差額即為廉價購買利益，歸屬於收購者，**列入當期損益**。[Ch1 p.6]

## 重點

### 計算公式
```
  移轉對價
+ 非控制權益（持股 < 100% 時）       → [[非控制權益]]
+ 原持有股權的收購日公允價值（分次收購時） → [[分次收購]]
= 被收購者權益依 IFRS 3 衡量之金額
− 被收購者可辨認淨資產公允價值
= 正數 → 商譽；負數 → 廉價購買利益
```

### 商譽的歸屬（持股 < 100% 時）[Ch1 p.7]
被收購者的權益包括 **控制權益**（收購者持有）與 **非控制權益**，商譽可以拆成兩部分 → 見 [[分次收購]] 書仁公司例題。

### 商譽記在哪裡？
- 吸收合併、創設合併：直接記在收購者帳上
- 股權收購：**不記在**母公司或子公司帳上，只出現在合併工作底稿與合併資產負債表 [Ch3 p.6] → [[合併沖銷原則]]

## 例題

### 【釋例】取得 100% 淨資產、有商譽：信義公司收購和平公司 [Ch1 p.6]
**題目摘要**：信義 X2/6/1 發行面額 $10、市價 $30 的普通股 4,000 股，取得和平公司所有淨資產，另以現金支付股票發行成本及會計師代辦費。合併前後資產負債表：

| | 合併前 | 合併後 | | 合併前 | 合併後 |
|---|---|---|---|---|---|
| 現金 | $180,000 | $215,000 | 負債 | $80,000 | $135,000 |
| 其他資產 | 240,000 | 340,000 | 普通股股本 | 160,000 | 200,000 |
| 商譽 | — | 25,000 | 資本公積 | 50,000 | 120,000 |
| | | | 保留盈餘 | 130,000 | 125,000 |
| 合計 | $420,000 | $580,000 | 合計 | $420,000 | $580,000 |

**考點**：題目沒給費用金額，要從「合併前後的變動」反推。

**步驟 1：反推每個數字**
| 項目 | 變動 | 推論 |
|---|---|---|
| 普通股股本 | +40,000 | 4,000 股 × $10 ✓ |
| 資本公積 | +70,000 | 發行溢價 4,000 × 20 = 80,000，所以**股票發行成本 = 10,000** |
| 保留盈餘 | −5,000 | **會計師代辦費 = 5,000**（費用） |
| 現金 | +35,000 | 取得和平的現金 − 付出 15,000 → **取得現金 = 50,000** |
| 其他資產 | +100,000 | 取得和平的其他資產 100,000 |
| 負債 | +55,000 | 承擔和平的負債 55,000 |

**步驟 2：算商譽**
- 和平可辨認淨資產公允價值 = 50,000 + 100,000 − 55,000 = 95,000
- 移轉對價 = 4,000 × $30 = 120,000
- 商譽 = 120,000 − 95,000 = **$25,000** ✓ 與合併後資產負債表一致

**步驟 3：分錄**
```
現金                  50,000
其他資產             100,000
商譽                  25,000
    負債                         55,000
    普通股股本                   40,000
    資本公積                     80,000

資本公積              10,000
合併費用               5,000
    現金                         15,000
```
✅ 驗算：合併前資產 420,000 + 50,000 + 100,000 + 25,000 − 15,000 = 580,000 ✓

更多例題：[[分次收購]]（智仁、書仁）、[[收購法]]（木柵）

## 常見錯誤 / 易混淆
- 算出廉價購買利益時，要先**重新評估及覆核**可辨認資產負債與對價的衡量，確認沒有算錯才能認列。[Ch1 p.6]
- 廉價購買利益列**當期損益**，不是資本公積。

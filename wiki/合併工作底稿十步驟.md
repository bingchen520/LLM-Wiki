# 合併工作底稿十步驟
> 收購日之後的每一年，都要用「工作底稿」把母子公司的報表合起來。工作底稿是一張大表：左邊放兩家公司各自的數字，中間做調整與沖銷，右邊就是合併報表。

## 定義
合併工作底稿：把母、子公司個別報表並列，透過調整與沖銷分錄編製合併綜合損益表、合併權益變動表、合併資產負債表的工具。調整與沖銷分錄**只出現在工作底稿**，不影響母子公司各自帳上的金額。[Ch5 p.2]

## 重點

### 收購日 vs. 收購日之後：為什麼每年都要重做？
**工作底稿上的調整與沖銷分錄，只出現在工作底稿，不會記進母子公司各自的帳** [Ch5 p.2]。所以母公司帳上永遠有「投資子公司」，子公司帳上永遠有自己的股本、保留盈餘，每年編合併報表時都要**從頭沖一次**。

| | 收購日（Ch3） | 收購日之後的每一年（Ch5） |
|---|---|---|
| 要編的報表 | 只有合併資產負債表 [Ch3 p.2] | 合併綜合損益表、合併權益變動表、合併資產負債表 [Ch5 p.1] |
| 母公司投資帳戶 | 剛買，等於移轉對價 | 權益法下已經加了投資收益、減了股利 [Ch2 p.1] |
| 差額 | 分攤到資產負債與商譽 | 分攤之外，還要做**當年度攤銷**（存貨→銷貨成本、設備→折舊）[Ch5 p.1] |
| 非控制權益 | 收購日的金額 | 收購日金額 ＋ 每年分到的淨利 − 股利 [Ch3 p.6] |
| 沖銷分錄 | 沖投資 vs. 權益、分攤差額、內部應收應付 [Ch3 p.2–3] | 多了：沖投資收益與股利、當年攤銷、NCI 淨利（五組分錄）[Ch5 p.1–2] |

### 十步驟 [Ch5 p.1]
1. 確認母公司是否完整採用權益法；沒有的話先調整成權益法 → [[不完全權益法與成本法的調整]]
2. 更正母公司或子公司帳上的錯誤與遺漏
3. 沖銷母子公司之間的交易及未實現（已實現）損益
4. **沖銷投資收益、OCI 份額與子公司給母公司的股利**，把投資帳戶還原成**期初**餘額
5. **沖銷期初投資帳戶與子公司期初權益**，列出期初 NCI 與未攤銷差額
6. 分攤期初未攤銷差額
7. 做當年度未攤銷差額的攤銷或調整
8. 列出**非控制權益淨利**（及 OCI）、沖銷 NCI 的股利，調整本期 NCI 變動
9. 沖銷母子公司之間的其他相對科目（應收應付等）
10. 算出合併欄各項目的餘額

### 核心觀念：期初餘額 vs. 本期變動數 [Ch5 p.1]
把「投資子公司」「非控制權益」和差額項目的期末餘額拆成兩部分：
- **期初餘額**：對應子公司**期初權益** → 編合併資產負債表
- **本期變動數**：對應子公司**本期損益與權益變動** → 編合併損益表、權益變動表

### 五組標準沖銷分錄 [Ch5 p.1–2]
五組分錄和十步驟的對應：分錄 ①＝步驟 4、②＝步驟 5、③＝步驟 6、④＝步驟 7、⑤＝步驟 8（步驟 1–3、9、10 視題目需要另外做）。達欣例題中寫成 (1)–(5)。
```
① 沖銷投資收益與股利，投資帳戶回到期初
   投資收益          XX
       股利                 XX
       投資子公司           XX

② 沖銷期初投資與子公司期初權益
   股本              XX
   保留盈餘（期初）  XX
   未攤銷差額        XX
       投資子公司           XX
       非控制權益（期初）   XX

③ 分攤未攤銷差額
   ○○資產           XX
       ○○負債              XX
       未攤銷差額           XX

④ 當年度攤銷（例如折舊）
   銷貨成本、費用等  XX
       未攤銷差額（或相關資產）XX

⑤ 非控制權益淨利
   非控制權益淨利    XX
       股利                 XX
       非控制權益           XX
```

### 其他注意事項 [Ch5 p.2]
1. 合併保留盈餘的淨利 = 合併收入 − 費用 − 非控制權益淨利
2. 母公司**完整**使用權益法時：**控制權益淨利 = 母公司淨利**、**合併保留盈餘 = 母公司保留盈餘**
3. 投資子公司與投資收益**一定會全部沖銷**，不會出現在合併報表

### 子公司有其他綜合損益時 [Ch5 p.9]
- 母公司認列：投資子公司 / 投資收益 / 其他綜合損益－子公司 OCI 份額
- 投資帳戶期末 = 期初 + 投資收益 + OCI 份額 − 股利
- 沖銷時多沖一個「OCI 份額」科目，NCI 分錄也要列出「非控制權益其他綜合損益」

## 例題（完整過程）

### 【釋例】權益法、取得控制年度：達欣公司與台啤公司 [Ch5 p.2]
**題目摘要**：達欣 X3/1/1 付現 $1,100,000 買台啤 80%，NCI 依公允價值 $250,000 衡量。台啤權益：股本 $840,000、保留盈餘 $240,000。存貨低估 $240,000（X3 年出售），廠房及設備高估 $144,000（剩 10 年，直線法）。商譽 X3 年未減損。

**考點**：用五組標準分錄完成第一年的合併工作底稿。

**步驟 1：差額分攤與 X3 年攤銷**
- 差額 = (1,100,000 + 250,000) − (840,000 + 240,000) = 270,000
- 商譽 = 270,000 − 240,000 + 144,000 = **174,000**

| 項目 | 差額 | X3 攤銷 | 影響 |
|---|---|---|---|
| 存貨 | +240,000 | 240,000 | 銷貨成本**增加** 240,000 |
| 廠房及設備 | −144,000 | 144,000 ÷ 10 = 14,400 | 折舊費用**減少** 14,400 |
| 商譽 | 174,000 | 0 | — |
| 合計 | 270,000 | 225,600 | 淨利減少 225,600 |

**步驟 2：母公司權益法數字（驗證母公司帳上是否正確）**
- 調整後子公司淨利 = 1,200,000 − 240,000 + 14,400 = 974,400
- 投資收益 = 974,400 × 80% = **779,520** ✓（與達欣帳上一致 → 完整權益法）
- NCI 淨利 = 974,400 × 20% = **194,880**
- 投資帳戶期末 = 1,100,000 + 779,520 − 624,000 × 80% = **1,380,320** ✓

**步驟 3：調整與沖銷分錄**
```
(1) 投資收益               779,520
        股利                        499,200   ← 624,000 × 80%
        投資台啤公司                280,320

(2) 股本－台啤             840,000
    保留盈餘－台啤（1/1）   240,000
    未攤銷差額              270,000
        投資台啤公司              1,100,000
        非控制權益                  250,000

(3) 存貨                   240,000
    商譽                   174,000
        廠房及設備                  144,000
        未攤銷差額                  270,000

(4) 銷貨成本               240,000
    廠房及設備              14,400
        存貨                        240,000
        費用（折舊）                 14,400

(5) 非控制權益淨利         194,880
        股利                        124,800   ← 624,000 × 20%
        非控制權益                   70,080
```

**步驟 4：工作底稿（合併欄）**
| 科目 | 達欣 | 台啤 | 合併 |
|---|---|---|---|
| 銷貨收入 | 4,120,480 | 3,360,000 | 7,480,480 |
| 投資收益 | 779,520 | — | — |
| 銷貨成本 | (2,000,000) | (1,230,000) | (3,470,000) |
| 費用 | (1,200,000) | (930,000) | (2,115,600) |
| 合併淨利 | | | 1,894,880 |
| 非控制權益淨利 | | | (194,880) |
| **控制權益淨利** | 1,700,000 | | **1,700,000** |
| 保留盈餘 12/31 | 1,100,000 | 816,000 | 1,100,000 |
| 存貨 | 110,000 | 330,000 | 440,000 |
| 廠房及設備（淨額） | 725,680 | 384,000 | 980,080 |
| 商譽 | | | 174,000 |
| 資產總額 | 3,296,000 | 2,040,000 | 4,000,080 |
| 非控制權益 | | | 320,080 |

✅ 驗算：
- 合併淨利 7,480,480 − 3,470,000 − 2,115,600 = 1,894,880 ✓
- 控制權益淨利 1,894,880 − 194,880 = 1,700,000 = 達欣淨利 ✓（完整權益法）
- NCI 期末 250,000 + 70,080 = 320,080 ✓
- 資產 410,000 + 706,000 + 440,000 + 1,290,000 + 980,080 + 174,000 = 4,000,080；負債及權益 1,080,000 + 1,500,000 + 1,100,000 + 320,080 = 4,000,080 ✓

## 常見錯誤 / 易混淆
- 分錄 ① 之後投資帳戶是「**期初**」餘額，分錄 ② 才沖得乾淨
- 子公司股利分成兩部分沖：母公司分到的 80% 在分錄 ①（跟投資收益一起沖）、NCI 分到的 20% 在分錄 ⑤（跟非控制權益淨利一起沖）；①⑤ 指上方「五組標準沖銷分錄」的編號
- 存貨低估 → 合併銷貨成本要**加**；設備高估 → 合併折舊要**減**

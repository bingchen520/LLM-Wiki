# 認列與衡量的例外
> 收購法原則上「所有東西都用收購日公允價值」，但有些項目 IFRS 3 規定用別的方法，這一頁整理這些例外。

## 定義
IFRS 3 對部分被收購者的資產、負債，訂定不同於一般「認列原則」與「公允價值衡量原則」的規定。[Ch4 p.5]

## 重點

| 項目 | 例外規定 | 來源 |
|---|---|---|
| **或有負債** | 只要是**過去事件導致的現時義務**且公允價值能可靠衡量，就算**不是很有可能**流出資源，收購日也要認列 | [Ch4 p.5] |
| **或有資產** | **禁止**認列 | [Ch4 p.5] |
| 所得稅 | 依 IAS 12 認列並衡量遞延所得稅資產、負債 | [Ch4 p.6] |
| 員工福利 | 依 IAS 19 衡量 | [Ch4 p.6] |
| **補償性資產** | 和被補償項目同時認列、用**相同衡量基礎**，並考量無法收現的金額 | [Ch4 p.6] |
| 被收購者為承租人的租賃 | 視為收購日的新租賃，依 IFRS 16 以剩餘租賃給付現值衡量租賃負債 | [Ch4 p.7] |
| **再取回權利** | 列為可辨認無形資產（和商譽分開），以**剩餘合約期間**為基礎衡量；條款有利或不利要認列結清損益 | [Ch4 p.7–8] |
| 股份基礎給付 | 依 IFRS 2 衡量（市價基礎衡量） | [Ch4 p.9] |
| 待出售資產 | 依 IFRS 5，以公允價值減出售成本衡量 | [Ch4 p.9] |
| 保險合約 | 依 IFRS 17 衡量 | [Ch4 p.9] |

### 或有負債的後續衡量 [Ch4 p.5]
取以下兩者**較高者**：
1. 依 IAS 37 會認列的金額
2. 原始認列金額（適當時減除依 IFRS 15 認列的累積收益）

### 補償性資產的後續處理 [Ch4 p.6]
用與被補償項目相同的基礎衡量；若後續非以公允價值衡量，要考量收現性；只有在收現、出售或喪失權利時才除列。

### 再取回權利的結清損益 [Ch4 p.7–8]
結清損益 = 下列較小者：(i) 條款相對市場條款有利或不利的金額；(ii) 合約約定不利一方解約時須支付的金額。若 (ii) < (i)，差額包含在企業合併的會計處理中。後續依剩餘合約期間攤銷。

## 例題（完整過程）

### 【釋例】或有負債：巧虎公司吸收合併益智公司 [Ch4 p.5–6]
**題目摘要**：巧虎 X8/1/1 付現 $550,000 吸收合併益智。益智流動資產低估 $100,000，其他帳面金額等於公允價值。益智涉及侵權訴訟，律師認為 80% 機率勝訴，所以益智依 IAS 37 沒有認列負債；巧虎估計這項或有負債公允價值 $20,000。X8/12/31 重新評估：90% 機率要賠 $30,000、10% 不用付。不考慮折現。

| 益智 X7/12/31 | 金額 |
|---|---|
| 流動資產 | 400,000 |
| 非流動資產 | 300,000 |
| 流動負債 | 80,000 |
| 非流動負債 | 120,000 |
| 權益總額 | 500,000 |

**考點**：IAS 37 不用認列（不是很有可能），但 IFRS 3 收購日**要**認列；後續取較高者。

**(1) X8/1/1 收購分錄**
- 可辨認淨資產公允價值 = (400,000 + 100,000) + 300,000 − 80,000 − 120,000 − 20,000 = 580,000
- 580,000 > 550,000 → **廉價購買利益 $30,000**
```
流動資產               500,000
非流動資產             300,000
    流動負債                       80,000
    非流動負債                    120,000
    估計專利權訴訟負債             20,000
    現金                          550,000
    廉價購買利益                   30,000
```

**(2) X8/12/31**
- 依 IAS 37：90% 很有可能要付 → 認列最可能金額 **$30,000**（補充：單一義務以最可能結果衡量）
- 原始認列金額 $20,000
- 取較高者 30,000 → 增加 10,000
```
估計專利權訴訟負債損失   10,000
    估計專利權訴訟負債             10,000
```
✅ 驗算：借 800,000 = 貸 80,000 + 120,000 + 20,000 + 550,000 + 30,000 = 800,000 ✓（與講義一致）
📌 如果沒有 IFRS 3 的例外，這 $20,000 不會被認列，算出來的廉價購買利益就會變成 $50,000。

## 常見錯誤 / 易混淆
- 或有負債：IAS 37 的「很有可能」門檻在企業合併**不適用**
- 或有**資產**不能認列（不對稱處理）

# 收購法（Acquisition Method）
> IFRS 3 規定企業合併唯一的會計方法：把「買到的東西」和「付出的代價」都用**收購日的公允價值**來衡量，差額就是商譽。

## 定義
以收購日之公允價值完整衡量企業合併中所涉及的各部分，並將「取得控制」視為須以公允價值再衡量之重大事項。[Ch1 p.2]

**業務（Business）**：一組經整合、能被經營與管理的活動及資產，目的在提供報酬給投資者。組成要素為「投入、處理過程、產出」。[Ch1 p.2]

## 重點

### 收購法的五個步驟 [Ch1 p.2–6]
1. **辨認收購者**：誰取得控制 → [[辨認收購者]]
2. **決定收購日**：收購者取得控制之日，通常是結清日，但依協議也可能在結清日之前或之後 [Ch1 p.3]
3. **認列與衡量被收購者的可辨認資產、負債及非控制權益** → [[非控制權益]]
4. **辨認與衡量移轉對價** → [[移轉對價]]、[[或有對價]]、[[收購相關成本]]
5. **認列與衡量商譽或廉價購買利益** → [[商譽與廉價購買利益]]

### 不適用收購法的交易 [Ch1 p.2]
a. 合資之成立
b. 取得一項或一組資產，但不構成「業務」
c. 共同控制下個體或業務之合併
d. 投資個體收購其投資子公司

### 步驟 3 的細節：認列與衡量 [Ch1 p.3–4]
- **認列條件**：(a) 符合資產、負債之定義；(b) 為企業合併交易之一部分（不是個別交易的結果）
- **分類及指定**：收購日就要把被收購者的資產負債分類，作為後續適用其他準則的依據
- **衡量原則**：以收購日公允價值衡量。公允價值（IFRS 13）= 衡量日市場參與者間有秩序交易中，出售資產可收取或移轉負債須支付之價格（**退出價格**、市場基礎，不是企業特定衡量）
- 特別注意：未來現金流量不確定之資產、被收購者為出租人之營業租賃、意圖不使用或用法不同之非金融資產、非控制權益
- 例外規定 → [[認列與衡量的例外]]

### 衡量期間 [Ch1 p.4]
- 衡量期間內：若取得「**收購日已存在**之事實或情況」的新資訊 → **追溯調整**收購日的暫定金額，必要時修正前期比較報表
- 衡量期間過後：只有「錯誤更正」才能修改企業合併的會計處理
- （補充）IFRS 3 規定衡量期間自收購日起**不超過一年**。

### 哪些交易不屬於企業合併的一部分（要拆出來）[Ch1 p.8–9]
1. 實質上是**結清收購者與被收購者合併前既存關係**的交易（例如雙方之間的訴訟）
2. 因被收購者員工或原業主**未來提供勞務**而給的酬勞
3. 補償被收購者或原業主**替收購者代墊收購相關成本**的交易

這些要依其他相關準則處理，不能算進移轉對價。

## 例題

### 【釋例】結清既存關係：木柵公司收購指南公司 [Ch1 p.8–9]
**題目摘要**：木柵公司 X2/1/1 付現 $800,000 吸收合併指南公司。合併前雙方有訴訟在進行，結清訴訟關係的收購日公允價值為 $75,000。指南公司可辨認淨資產公允價值 $650,000（不含訴訟相關項目）。

**考點**：付出的 $800,000 裡，有一部分其實是在「結清訴訟」，要先拆出來，剩下的才是企業合併的移轉對價。

**(a) 指南告木柵（木柵是被告，帳上已認列負債準備 $55,000）**
木柵等於多付 $75,000 給指南來和解：
- 和解金額 $75,000 vs 帳上負債 $55,000 → 損失 $20,000
- 企業合併移轉對價 = 800,000 − 75,000 = 725,000
- 商譽 = 725,000 − 650,000 = **$75,000**

```
結清訴訟損失          20,000
負債準備－專利訴訟     55,000
    現金                      75,000

指南公司可辨認淨資產   650,000
商譽                   75,000
    現金                     725,000
```
✅ 驗算：兩筆分錄現金合計 75,000 + 725,000 = 800,000，與付出的現金相符。

**(b) 木柵告指南（木柵是原告，帳上沒有認列或有資產）**
指南欠木柵 $75,000，等於木柵「收回」了 $75,000：
- 移轉對價 = 800,000 + 75,000 = 875,000
- 商譽 = 875,000 − 650,000 = **$225,000**

```
現金                   75,000
    結清訴訟利益               75,000

指南公司可辨認淨資產   650,000
商譽                  225,000
    現金                     875,000
```
✅ 驗算：現金淨流出 875,000 − 75,000 = 800,000。

## 常見錯誤 / 易混淆
- 收購相關成本（律師費等）**不算**移轉對價 → [[收購相關成本]]
- 衡量期間調整是「追溯」到收購日；超過衡量期間的新資訊、或屬於收購日後才發生的事項，**不能**回頭調整商譽。

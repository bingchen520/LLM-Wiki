# 收購相關成本（Acquisition-related Costs）
> 為了完成合併而花的錢（律師費、會計師費、發行股票的費用），**不算**買價，依性質另外處理。

## 定義
收購者為完成企業合併所發生的成本，**不包含**在移轉對價內。[Ch1 p.5]

## 重點

### 三種處理方式 [Ch1 p.5]
| 成本類型 | 例子 | 處理 |
|---|---|---|
| 股票發行成本 | 股票登記費、新股印製成本 | **減少資本公積** |
| 債券發行成本 | 債券發行費用 | 調整債券溢折價，於流通期間攤銷 |
| 其他收購相關成本 | 律師費、會計師費、顧問費、發起人酬勞 | **當期費用** |

**口訣**：發股票 → 扣資本公積；發債券 → 調溢折價；其他 → 費用。

## 例題

### 【釋例】收購相關成本：甲公司新設合併乙、丙 [Ch1 p.5]
**題目摘要**：甲公司新設立，發行面額 $10、市價 $24 的普通股 3,000 股，取得乙、丙兩家公司的全部淨資產。另支付律師及會計師公費 $3,600、股票登記費 $1,000、新股印製成本 $1,500。乙公司原股東取得 1,800 股，丙公司原股東取得 1,200 股。

| | 乙公司 | 丙公司 |
|---|---|---|
| 普通股股本 | $10,000 | $15,000 |
| 資本公積 | 8,000 | 3,000 |
| 保留盈餘 | 7,000 | 2,000 |
| 合計 | $25,000 | $20,000 |

問：收購法下，合併後普通股股本與資本公積金額？

**考點**：分辨哪些成本扣資本公積、哪些列費用。

**解法（甲公司發行股票出資 → 甲是收購者）**
- 股本 = 3,000 股 × $10 = **$30,000**
- 發行溢價 = 3,000 × (24 − 10) = $42,000
- 股票發行成本 = 1,000 + 1,500 = $2,500 → 扣資本公積
- 資本公積 = 42,000 − 2,500 = **$39,500**
- 律師及會計師公費 $3,600 → 當期費用
```
（取得乙、丙淨資產）     72,000
    普通股股本                     30,000
    資本公積                       42,000
資本公積                  2,500
合併費用                  3,600
    現金                            6,100
```

✅ 驗算：借 72,000 + 2,500 + 3,600 = 78,100；貸 30,000 + 42,000 + 6,100 = 78,100
📌 Ch1 例題一律以「出錢（付現或發行股票）的公司」為收購者。換股後由被收購方股東掌握控制的情況屬於 [[反向收購]]，在 Ch4 處理。

### 【釋例】信義公司的收購相關成本 [Ch1 p.6]
信義公司發行股票時，以現金支付股票發行成本 $10,000、會計師代辦費用 $5,000（由合併前後資產負債表反推，見 [[商譽與廉價購買利益]]）：
```
資本公積              10,000
合併費用               5,000
    現金                       15,000
```

## 常見錯誤 / 易混淆
- 把律師費、會計師費加進投資成本或商譽 ❌（IFRS 3 修正後一律列費用）
- 發起人酬勞屬於「其他收購相關成本」→ 列費用（Ch3 泰順公司例題會用到）

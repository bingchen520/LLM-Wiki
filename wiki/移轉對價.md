# 移轉對價（Consideration Transferred）
> 收購者為了取得控制「付出的代價」，全部用收購日的公允價值計算。

## 定義
移轉對價 = 下列三者於**收購日公允價值**的合計數：[Ch1 p.4]
1. 收購者所移轉之資產（如現金）
2. 收購者所發生之負債（如發行公司債）
3. 收購者所發行之權益（如發行股票）

## 重點
- 移轉對價的形式：現金或其他資產、發行債券、發行權益證券等 [Ch1 p.1, p.4]
- **或有對價**也要在收購日以公允價值算進移轉對價 → [[或有對價]]
- **收購相關成本不算**移轉對價 → [[收購相關成本]]
- 結清既存關係等「非屬企業合併之一部分」的交易要先拆出 → [[收購法]]
- 發行股票作為對價時：股本按**面額**、超過面額的部分記**資本公積**

### 公式
```
移轉對價（+ 非控制權益 + 原持有股權公允價值）
− 被收購者可辨認淨資產公允價值
= 商譽（正數）或 廉價購買利益（負數）
```
→ [[商譽與廉價購買利益]]

## 例題
- 發行股票作為對價：[[商譽與廉價購買利益]]（信義公司）、[[收購相關成本]]（甲公司）
- 含或有對價：[[或有對價]]（巨歐公司）
- 現金＋結清訴訟：[[收購法]]（木柵公司）

## 常見錯誤 / 易混淆
- 發行股票要用**市價**（公允價值）計算，不是用面額。

# 未攤銷差額（Excess of Cost over Book Value）
> 母公司買子公司時，是用「公允價值」買的；但子公司自己的帳還是「帳面金額」。兩者之間的差距叫**差額**，要分到各個資產、負債上，之後隨著資產用掉、賣掉慢慢攤銷。

## 定義
「移轉對價 + 非控制權益」與「子公司可辨認淨資產**帳面金額**」之間的差額。[Ch2 p.2]

可能原因：[Ch2 p.2]
1. 子公司可辨認淨資產的帳面金額**低估或高估**
2. 子公司有**商譽**，或企業合併產生**廉價購買利益**

## 重點

### 步驟 1：差額分攤
```
  移轉對價 + 非控制權益
− 子公司權益帳面金額
= 差額
  − 各項資產低估數（+）／高估數（−）
  − 各項負債高估數（+）／低估數（−）
= 商譽（剩下的部分）
```

### 步驟 2：差額攤銷，怎麼影響投資收益？[Ch2 p.2]
```
淨資產低估 → 子公司的費用、成本低估 → 淨利高估 → 投資收益高估（要往下調）
淨資產高估 → 子公司的費用、成本高估 → 淨利低估 → 投資收益低估（要往上調）
```
計算投資收益前，要先把子公司帳列淨利調整成「如果淨資產沒有高估或低估時應有的淨利」，再乘以持股比例。[Ch2 p.2]

| 差額項目 | 什麼時候攤銷 | 影響的科目（補充） |
|---|---|---|
| 存貨 | 存貨**出售**當年一次攤完 | 銷貨成本 |
| 設備、房屋 | 依剩餘耐用年限 | 折舊費用 |
| 土地 | 不攤銷，**出售時**一次轉銷 [Ch2 p.4] | 處分損益 |
| 應付票據、公司債 | 依剩餘期限 | 利息費用 |
| 商譽 | **不攤銷**，每年做減損測試 [Ch2 p.2] | — |

### 步驟 3：核心公式（補充整理）
```
投資收益 = （子公司帳列淨利 ± 差額攤銷）× 持股比例
投資帳戶期末 = 期初 + 投資收益 − 子公司股利 × 持股比例
投資帳戶 = 股權淨值（子公司權益帳面 × 持股比例）+ 歸屬於母公司的未攤銷差額
```
最後一條是**驗算神器**：兩種方法算出的投資帳戶一定要相等。（有廉價購買且 NCI 用公允價值衡量時例外，見下方特殊情況 6）[Ch2 p.7]

### 特殊情況 [Ch2 p.4–7]
1. **子公司處分高估或低估的資產**：相關的未攤銷差額**一次攤銷**
2. **子公司虧損**：母公司仍按比例認列投資損失；投資帳戶變成負數時，在母公司報表上列為**負債**
3. **子公司其他綜合損益變動**（例如不動產重估價、FVOCI 金融資產價值增減）：母公司調整投資帳面金額，並認列為母公司的**其他綜合損益**
4. **期中取得控制**：投資收益只用**收購日後**子公司賺的淨利計算；攤銷也只算收購日後到年底的部分
5. **直接向子公司購買新發行的股票**：子公司淨資產和流通在外股數都會增加，持股比例和商譽要按**發行新股後**的狀況計算
6. **廉價購買 + NCI 以公允價值衡量**：「投資帳戶 − 股權淨值 = 母公司未攤銷差額」這條關係**不再成立**，要再減掉「原本應歸屬 NCI 的商譽」

### 在合併工作底稿上 [Ch5 p.6]
- 取得控制年度：期初未攤銷差額 = 原始差額
- 以後年度：期初未攤銷差額 = 原始差額 − 已攤銷數
- 先分攤到各資產負債與商譽（程序 6），再做當年度攤銷（程序 7）→ [[合併工作底稿十步驟]]

## 例題（完整過程）

### 【釋例】瓊安公司投資瓊斯公司 [Ch2 p.3]
**題目摘要**：瓊安 X3/1/1 付現 $750,000 買瓊斯 80%，NCI 依公允價值 $186,000 衡量。瓊斯權益：股本 $500,000、保留盈餘 $300,000。存貨低估 $70,000（X3 年全部出售）、設備低估 $30,000（剩 6 年，直線法）。瓊斯 X3 淨利 $100,000、現金股利 $80,000。

**考點**：基本的差額分攤與攤銷，以及兩種方法驗算投資帳戶。

**步驟 1：差額分攤**
- 差額 = (750,000 + 186,000) − (500,000 + 300,000) = 136,000
- 商譽 = 136,000 − 70,000 − 30,000 = 36,000
  - 母公司：750,000 − 80% × (800,000 + 100,000) = 30,000
  - NCI：186,000 − 20% × 900,000 = 6,000

**步驟 2：差額攤銷表**
| 項目 | X3 初未攤銷差額 | 年限 | X3 攤銷 | X3 底未攤銷差額 | 母公司 80% | NCI 20% |
|---|---|---|---|---|---|---|
| 存貨 | 70,000 | 1 | (70,000) | 0 | 0 | 0 |
| 設備 | 30,000 | 6 | (5,000) | 25,000 | 20,000 | 5,000 |
| 商譽 | 36,000 | — | 0 | 36,000 | 30,000 | 6,000 |
| 合計 | 136,000 | | (75,000) | 61,000 | 50,000 | 11,000 |

📌 商譽**不按 80/20 分**，要用步驟 1 算出的 30,000／6,000。

**步驟 3：計算**
| 問題 | 計算 | 答案 |
|---|---|---|
| (1) X3 投資收益 | (100,000 − 75,000) × 80% | **$20,000** |
| (2) X3 底投資帳戶 | 750,000 + 20,000 − 80,000 × 80% | **$706,000** |
| (3) X3 底股權淨值 | (800,000 + 100,000 − 80,000) × 80% | **$656,000** |
| (4) 母公司未攤銷差額 | 20,000 + 30,000 | **$50,000** |

**分錄**
```
X3/1/1   投資瓊斯公司   750,000  /  現金          750,000
股利     現金            64,000  /  投資瓊斯公司   64,000
X3/12/31 投資瓊斯公司    20,000  /  投資收益       20,000
```
✅ 驗算：股權淨值 656,000 + 母公司未攤銷差額 50,000 = 706,000 = 投資帳戶 ✓

### 【釋例】期中取得控制：安娜公司投資安麗公司 [Ch2 p.6]
**題目摘要**：安娜 X7/10/1 以 $1,480,000 買安麗 80%，NCI 依公允價值 $350,000 衡量。安麗權益 $1,500,000；存貨高估 $50,000（X7 年底前出售）、設備低估 $150,000（剩 5 年，直線法）。

| | X7 年 | X8 年 |
|---|---|---|
| 淨利（一年內平均賺得） | $360,000 | $450,000 |
| 股利（每年 12 月發放） | 150,000 | 250,000 |

**考點**：年中取得 → 淨利和設備攤銷都只算 3 個月（10/1–12/31）；存貨高估要「加回」。

**步驟 1：差額分攤**
- 差額 = (1,480,000 + 350,000) − 1,500,000 = 330,000
- 可辨認淨資產公允價值 = 1,500,000 − 50,000 + 150,000 = 1,600,000
- 商譽 = 1,830,000 − 1,600,000 = 230,000
  - 母公司：1,480,000 − 80% × 1,600,000 = **200,000** ← 第 (1) 小題答案
  - NCI：350,000 − 20% × 1,600,000 = 30,000

**步驟 2：差額攤銷表**
| 項目 | X7/10/1 未攤銷差額 | 年限 | X7 攤銷 | X8 攤銷 | X8 底未攤銷差額 | 母公司 80% | NCI 20% |
|---|---|---|---|---|---|---|---|
| 存貨 | (50,000) | 1 | 50,000 | — | — | — | — |
| 設備 | 150,000 | 5 | (7,500)* | (30,000) | 112,500 | 90,000 | 22,500 |
| 商譽 | 230,000 | — | 0 | 0 | 230,000 | 200,000 | 30,000 |
| 合計 | **330,000** | | 42,500 | (30,000) | 342,500 | 290,000 | 52,500 |

\* 150,000 ÷ 5 × 3/12 = 7,500

⚠️ 講義疑誤：講義的「合計」寫 **$136,000**，應為 **$330,000**。
- 證明：330,000 + 42,500 − 30,000 = 342,500，與講義自己算的 X8 年底合計一致；若用 136,000 會得到 148,500，對不上。
- 推測原因：$136,000 是前一題（瓊安）的合計數，複製表格時忘了改。

📌 存貨高估 50,000：存貨賣掉時，子公司的銷貨成本多算了 50,000，所以要把 50,000 **加回**子公司淨利。

**步驟 3：計算**
| 問題 | 計算 | 答案 |
|---|---|---|
| (2) X7 投資收益 | (360,000 × 3/12 + 50,000 − 7,500) × 80% = 132,500 × 80% | **$106,000** |
| (3) X7 底投資帳戶 | 1,480,000 + 106,000 − 150,000 × 80% | **$1,466,000** |
| (4) X8 投資收益 | (450,000 − 30,000) × 80% | **$336,000** |
| (5) X8 底投資帳戶 | 1,466,000 + 336,000 − 250,000 × 80% | **$1,602,000** |
| (6) X8 底股權淨值 | (1,500,000 + 90,000 − 150,000 + 450,000 − 250,000) × 80% = 1,640,000 × 80% | **$1,312,000** |
| (7) X8 底母公司未攤銷差額 | 90,000 + 200,000 | **$290,000** |

📌 X7 的股利 $150,000 在 12 月發放，在收購日之後，所以要全部按比例沖減投資帳戶。

**分錄（X7）**
```
X7/10/1   投資安麗公司  1,480,000  /  現金          1,480,000
X7/12     現金            120,000  /  投資安麗公司     120,000
X7/12/31  投資安麗公司    106,000  /  投資收益         106,000
```
✅ 驗算 X8：股權淨值 1,312,000 + 母公司未攤銷差額 290,000 = 1,602,000 = 投資帳戶 ✓
✅ 驗算 X7：股權淨值 1,440,000 × 80% = 1,152,000；母公司未攤銷差額 = 142,500 × 80% + 200,000 = 314,000；合計 1,466,000 ✓

## 常見錯誤 / 易混淆
- 商譽的未攤銷差額直接用持股比例拆 ❌（NCI 用公允價值衡量時，母公司和 NCI 的商譽要分開算）
- 期中取得，用全年淨利算投資收益 ❌
- 存貨**高估**時還去減淨利 ❌（高估 → 成本多算 → 要加回）

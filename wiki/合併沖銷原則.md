# 合併沖銷原則
> 合併報表就是「把母公司和子公司當成同一家公司」來編報表。做法很簡單：**同一家公司內部的東西互相抵掉，對外的東西加起來。**

## 定義
編製合併報表的基本原則：[Ch3 p.2]
1. **相對科目沖銷**：例如母公司的「投資子公司」和子公司的「權益」、母子公司之間的應收與應付
2. **非相對科目合併**：其他科目直接相加

## 重點

### 為什麼要沖銷？（補充說明）
- 母公司帳上的「投資子公司」，代表的就是子公司的淨資產。合併時已經把子公司的資產、負債一項一項加進來，如果投資帳戶也留著，就重複計算了。
- 母公司欠子公司 $30,000，在「同一家公司」的觀點下，等於自己欠自己，所以應收、應付都要抵掉。

### 編製合併報表的前提 [Ch3 p.1–2]
- **所有子公司都要納入**，即使是打算出售的子公司（IFRS 5 待出售）也要納入，只是要把它的資產負債分開列示 [Ch3 p.1]
- **報導日不一致**：子公司要另外編製與母公司同一天的財務資訊；實務上不可行時，差異不得超過 **3 個月**，且每期要一致，並調整期間內的重大交易 [Ch3 p.2]
- **會計政策不一致**：先調整成員的報表，再合併 [Ch3 p.2]

### 收購日的沖銷分錄 [Ch3 p.2–3]
```
股本－子公司            XX
資本公積－子公司        XX
保留盈餘－子公司        XX
未攤銷差額              XX
    投資子公司                  XX
    非控制權益                  XX   ← 持股 < 100% 才有

○○資產（低估數）       XX
商譽                    XX
    ○○資產（高估數）           XX
    未攤銷差額                  XX
```
講義有時把兩筆合成一筆，直接把差額分到各資產負債和商譽。[Ch3 p.2–3]

### 其他補充說明 [Ch3 p.6]
1. **合併商譽**在母公司或子公司帳上都沒有記錄，只出現在工作底稿和合併資產負債表
2. 收購日合併資產負債表上：**子公司**淨資產按公允價值，**母公司**淨資產仍按原帳面金額
3. 合併資產負債表上的股本、資本公積、保留盈餘 = **母公司**本身的金額（子公司權益全部被沖掉）
4. **非控制權益**列在合併資產負債表的**權益**中，與母公司權益分開列示

### 收購日後的合併 [Ch3 p.6]
- 先確定母公司已**完整**使用權益法
- 非控制權益 = 收購日的 NCI ＋ 收購日後子公司權益變動中歸屬於 NCI 的份額
- 每年的沖銷程序 → [[合併工作底稿十步驟]]

### 其他合併報表 [Ch3 p.7–9]
| 報表 | 重點 |
|---|---|
| 合併綜合損益表 | 合併淨利要分成「歸屬於母公司（控制權益淨利）」和「歸屬於非控制權益」；**不再列投資收益**；差額攤銷依性質反映在銷貨成本、折舊、利息費用 |
| 合併權益變動表 | 只有母公司權益要分股本、資本公積、保留盈餘；NCI 只列一欄 |
| 合併現金流量表 | 支付給 NCI 的股利可列營業或籌資活動；取得或喪失子公司控制的現金流量列**投資活動**；持股變動但沒有喪失控制列**籌資活動** |

## 例題（完整過程）

### 【釋例】持股 100%：美東公司收購美西公司 [Ch3 p.3]
**題目摘要**：美東 X3/1/1 發行面額 $780,000、公允價值 $800,000 的公司債，取得美西全部股權。美西的應收帳款公允價值 $320,000（帳面 $300,000）、存貨公允價值 $490,000（帳面 $500,000），其他項目帳面金額等於公允價值。美西對美東有 $30,000 的應收帳款。

**考點**：100% 持股的基本沖銷，加上母子公司之間的應收應付沖銷。

**步驟 1：算差額**
- 美西權益帳面 = 500,000 + 100,000 + 150,000 = 750,000
- 差額 = 800,000 − 750,000 = 50,000
- 分攤：應收帳款 +20,000、存貨 −10,000 → 商譽 = 50,000 − 20,000 + 10,000 = **40,000**

**步驟 2：沖銷分錄**
```
(1) 普通股股本－美西     500,000
    資本公積－美西       100,000
    保留盈餘－美西       150,000
    未攤銷差額            50,000
        投資美西公司               800,000

(2) 應收帳款              20,000
    商譽                  40,000
        存貨                        10,000
        未攤銷差額                  50,000

(3) 應付帳款              30,000     ← 美東欠美西，內部交易
        應收帳款                    30,000
```

**步驟 3：合併資產負債表工作底稿**
| 科目 | 美東 | 美西 | 借 | 貸 | 合併 |
|---|---|---|---|---|---|
| 現金 | 240,000 | 150,000 | | | 390,000 |
| 應收帳款 | 360,000 | 300,000 | (2) 20,000 | (3) 30,000 | 650,000 |
| 存貨 | 400,000 | 500,000 | | (2) 10,000 | 890,000 |
| 投資美西公司 | 800,000 | | | (1) 800,000 | — |
| 商譽 | | | (2) 40,000 | | 40,000 |
| 未攤銷差額 | | | (1) 50,000 | (2) 50,000 | — |
| **資產總額** | 1,800,000 | 950,000 | | | **1,970,000** |
| 應付帳款 | 200,000 | 200,000 | (3) 30,000 | | 370,000 |
| 應付公司債（淨額） | 800,000 | | | | 800,000 |
| 普通股股本 | 400,000 | 500,000 | (1) 500,000 | | 400,000 |
| 資本公積 | 150,000 | 100,000 | (1) 100,000 | | 150,000 |
| 保留盈餘 | 250,000 | 150,000 | (1) 150,000 | | 250,000 |
| **負債及權益總額** | 1,800,000 | 950,000 | | | **1,970,000** |

✅ 驗算：資產 390 + 650 + 890 + 40 = 1,970 千；負債及權益 370 + 800 + 400 + 150 + 250 = 1,970 千 ✓；借方合計 890,000 = 貸方合計 890,000 ✓（與講義一致）
📌 合併後的股本、資本公積、保留盈餘 = 美東自己的金額。

### 【釋例】持股 80%：泰順公司收購泰安公司 [Ch3 p.4–5]
**題目摘要**：泰順 X6/10/1 發行面額 $10、市價 $24 的普通股 20,000 股，取得泰安 80%，NCI 依公允價值 $112,000 衡量。另付現 $50,000：70% 是發起人酬勞，30% 是股票登記費。泰安僅存貨（公允價值 $300,000）、設備（$370,000）、長期負債（$280,000）的公允價值與帳面金額不同。

| 泰安 X6/9/30 | 帳面 | 公允價值 |
|---|---|---|
| 現金 | 100,000 | 100,000 |
| 應收帳款 | 150,000 | 150,000 |
| 存貨 | 250,000 | 300,000 |
| 設備 | 400,000 | 370,000 |
| 流動負債 | 100,000 | 100,000 |
| 長期負債 | 300,000 | 280,000 |
| 股本 | 400,000 | |
| 保留盈餘 | 100,000 | |

**考點**：持股 < 100% 會出現非控制權益；收購相關成本的處理（Ch1）。

**(1) 泰順的收購分錄**
```
投資泰安公司          480,000     ← 20,000 × 24
    普通股股本                200,000   ← 20,000 × 10
    資本公積                  280,000

合併費用               35,000     ← 50,000 × 70%，發起人酬勞 → 費用
資本公積               15,000     ← 50,000 × 30%，股票登記費 → 扣資本公積
    現金                       50,000
```
✅ 和講義工作底稿上泰順的數字核對：現金 150,000 − 50,000 = 100,000 ✓；股本 600,000 + 200,000 = 800,000 ✓；資本公積 280,000 − 15,000 = 265,000 ✓；保留盈餘 400,000 − 35,000 = 365,000 ✓

**(2) 算差額與商譽**
- 泰安可辨認淨資產公允價值 = (100 + 150 + 300 + 370) − (100 + 280) = 540,000
- 移轉對價 + NCI = 480,000 + 112,000 = 592,000
- 差額 = 592,000 − 500,000（帳面權益）= 92,000
- 商譽 = 592,000 − 540,000 = **52,000**（母公司 480,000 − 432,000 = 48,000；NCI 112,000 − 108,000 = 4,000）

**沖銷分錄**
```
(1) 普通股股本－泰安     400,000
    保留盈餘－泰安       100,000
    未攤銷差額            92,000
        投資泰安公司               480,000
        非控制權益                 112,000

(2) 存貨                  50,000
    長期負債              20,000     ← 負債高估，要減少
    商譽                  52,000
        設備                        30,000
        未攤銷差額                  92,000
```

**合併資產負債表工作底稿**
| 科目 | 泰順 | 泰安 | 借 | 貸 | 合併 |
|---|---|---|---|---|---|
| 現金 | 100,000 | 100,000 | | | 200,000 |
| 應收帳款 | 250,000 | 150,000 | | | 400,000 |
| 存貨 | 300,000 | 250,000 | (2) 50,000 | | 600,000 |
| 投資泰安公司 | 480,000 | | | (1) 480,000 | — |
| 設備 | 500,000 | 400,000 | | (2) 30,000 | 870,000 |
| 商譽 | | | (2) 52,000 | | 52,000 |
| 未攤銷差額 | | | (1) 92,000 | (2) 92,000 | — |
| **資產總額** | 1,630,000 | 900,000 | | | **2,122,000** |
| 流動負債 | 200,000 | 100,000 | | | 300,000 |
| 長期負債 | | 300,000 | (2) 20,000 | | 280,000 |
| 普通股股本 | 800,000 | 400,000 | (1) 400,000 | | 800,000 |
| 資本公積 | 265,000 | | | | 265,000 |
| 保留盈餘 | 365,000 | 100,000 | (1) 100,000 | | 365,000 |
| 非控制權益 | | | | (1) 112,000 | 112,000 |
| **負債及權益總額** | 1,630,000 | 900,000 | | | **2,122,000** |

✅ 驗算：資產 200 + 400 + 600 + 870 + 52 = 2,122 千；負債及權益 300 + 280 + 800 + 265 + 365 + 112 = 2,122 千 ✓；借 714,000 = 貸 714,000 ✓

## 常見錯誤 / 易混淆
- 把子公司的股本、保留盈餘也加進合併報表 ❌（全部沖掉，合併權益 = 母公司權益 + NCI）
- 忘了沖銷母子公司之間的應收應付 ❌
- 合併損益表還列「投資收益」❌

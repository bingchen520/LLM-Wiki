# 不完全權益法與成本法的調整
> 合併工作底稿的前提是「母公司有正確使用權益法」。如果母公司用錯了（不完全權益法）或用成本法，編合併報表前要先在工作底稿上**調整成權益法**的數字。

## 定義
- **不完全權益法**：母公司想用權益法，但用得不完整（例如漏了差額攤銷），導致母公司淨利、保留盈餘 ≠ 合併報表的控制權益淨利、合併保留盈餘。[Ch5 p.3]
- **成本法**：投資帳戶始終維持最初投資金額，子公司發股利時認列「股利收入」。[Ch5 p.4]

## 重點

### 每次編工作底稿前，一定先檢查 [Ch5 p.3]
母公司帳上的「投資收益」和「投資帳戶」，是不是權益法下應有的金額？

### 不完全權益法的調整 [Ch5 p.3]
| 時點 | 錯在哪裡 | 調整分錄（假設投資收益高估） |
|---|---|---|
| 取得控制年度 | 投資收益、投資帳戶 | 投資收益 XX / 投資子公司 XX |
| 以後年度 | **本期**差異 → 投資收益；**前期**差異 → 期初保留盈餘；兩者累計 → 投資帳戶 | 投資收益 XX、保留盈餘（1/1）XX / 投資子公司 XX |

### 成本法的調整 [Ch5 p.4]
| 時點 | 調整分錄 |
|---|---|
| 取得控制年度 | 股利收入 XX、投資子公司 XX / 投資收益 XX |
| 以後年度 | 股利收入 XX、投資子公司 XX / 投資收益 XX、保留盈餘（1/1）XX |

**期初保留盈餘要調整多少？** = 投資後子公司保留盈餘增加數（未分配淨利）± 累計差額攤銷數，再乘以持股比例 [Ch5 p.4]

調整完之後，其他沖銷步驟都和權益法一樣 → [[合併工作底稿十步驟]]

## 例題（完整過程）

### 【釋例】成本法、取得控制以後年度：可曉公司投資藝曉公司 [Ch5 p.5]
**題目摘要**：可曉 X2 年初以 $500,000 買藝曉 80%，藝曉資產負債帳面等於公允價值（沒有差額）。藝曉投入資本一直是 $300,000。

| 年度 | 股利（7/1 發放） | 淨利 |
|---|---|---|
| X1 | 100,000 | 350,000 |
| X2 | 220,000 | 280,000 |
| X3 | 350,000 | 320,000 |

**考點**：同一筆投資，權益法和成本法的帳差在哪裡，以及工作底稿怎麼調。

**(1) 如果用權益法**
X3 年分錄：
```
X3/7/1     現金              280,000     ← 350,000 × 80%
               投資藝曉公司          280,000
X3/12/31   投資藝曉公司      256,000     ← 320,000 × 80%
               投資收益              256,000
```
投資帳戶 X3 年底 = 500,000 + (280,000 − 220,000) × 80% + (320,000 − 350,000) × 80%
　　　　　　　 = 500,000 + 48,000 − 24,000 = **$524,000**

📌 X1 年是投資**前**的數字，與母公司無關，是干擾數字。

**(2) 如果用成本法**
X3 年分錄：
```
X3/7/1     現金              280,000
               股利收入              280,000
```
投資帳戶 X3 年底 = **$500,000**（維持原始成本）

**(3) 工作底稿上把成本法調整成權益法**
| 項目 | 成本法帳上 | 權益法應有 | 調整 |
|---|---|---|---|
| X3 股利收入 | 280,000 | 0 | 沖掉 280,000 |
| X3 投資收益 | 0 | 256,000 | 補認列 256,000 |
| 期初保留盈餘（X2 的差異） | — | (280,000 − 220,000) × 80% = 48,000 | 增加 48,000 |
| 投資帳戶 | 500,000 | 524,000 | 增加 24,000 |

```
股利收入              280,000
投資藝曉公司           24,000
    投資收益                    256,000
    保留盈餘（1/1）              48,000
```
✅ 驗算：借 304,000 = 貸 304,000 ✓；成本法 500,000 + 24,000 = 權益法 524,000 ✓（與講義一致）

## 常見錯誤 / 易混淆
- 成本法調整時，把「前期」差異也放進投資收益 ❌（前期差異 → 期初保留盈餘）
- 把投資前的子公司保留盈餘變動也算進調整 ❌（只算投資**後**的增加數）

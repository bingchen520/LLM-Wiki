# 分次收購（Business Combination Achieved in Stages）
> 先買一小部分股權，之後再加碼買到取得控制。取得控制那天，原本持有的股權要先用公允價值「假裝賣掉再買回來」。

## 定義
視同投資者將原有投資以**收購日公允價值處分**後，立即再以相同之公允價值買回該投資，進而改變該投資之分類及衡量。[Ch1 p.7]

## 重點
1. 原持有股權**再衡量至收購日公允價值**
2. 再衡量的差額依原投資的分類處理（補充）：
   - 原本是「透過損益按公允價值衡量」→ 列損益
   - 原本是「透過其他綜合損益按公允價值衡量（FVOCI）」的權益工具 → 列其他綜合損益，**不重分類**到損益，可轉入保留盈餘
3. 商譽 = 新付的對價 + 原持有股權公允價值 + 非控制權益 − 可辨認淨資產公允價值

## 例題

### 【釋例】分次收購，持股 100%：智仁公司收購智勇公司 [Ch1 p.7]
**題目摘要**：
- X2/1/1：智仁付現 $240,000 買智勇 15%，分類為 FVOCI
- X2–X4：OCI 累計認列公允價值增加 $45,000 → 帳面金額 = 240,000 + 45,000 = $285,000
- X5/3/1：智仁再付現 $1,800,000 買其餘 85%。當日智勇可辨認淨資產公允價值 $1,750,000，原 15% 股權公允價值 $300,000

**考點**：原持有的 15% 要先再衡量到 $300,000，再一起算商譽。

**分錄**
```
① 原 15% 再衡量至公允價值（300,000 − 285,000）
透過其他綜合損益按公允價值衡量之權益工具投資   15,000
    其他綜合損益－權益工具投資未實現評價損益          15,000

② （選擇性，補充）累計 OCI 轉入保留盈餘（45,000 + 15,000）
其他權益－權益工具投資未實現評價損益          60,000
    保留盈餘                                          60,000

③ 取得控制
投資智勇公司                             2,100,000
    透過其他綜合損益按公允價值衡量之權益工具投資     300,000
    現金                                          1,800,000
```

**商譽**
= 1,800,000 + 300,000 − 1,750,000 = **$350,000**
（股權收購：商譽不記在智仁帳上，編合併報表時才出現。）

✅ 驗算：投資帳戶 2,100,000 = 可辨認淨資產 1,750,000 + 商譽 350,000

### 【釋例】分次收購，持股 < 100%：書仁公司收購書文公司 [Ch1 p.8]
**題目摘要**：書仁原持有書文 10%，X7/12/31 再付現 $800,000 買 75%（合計 85%）。當日：書文可辨認淨資產公允價值 $1,000,000、原 10% 公允價值 $105,000、15% NCI 公允價值 $157,500，依公允價值衡量 NCI。

**(1) 商譽**
```
  新付對價            800,000
+ 原 10% 公允價值      105,000
+ NCI 公允價值         157,500
= 1,062,500
− 可辨認淨資產公允價值 1,000,000
= 商譽                 62,500
```

**(2) 商譽歸屬**
- 控制權益（85%）：(800,000 + 105,000) − 1,000,000 × 85% = 905,000 − 850,000 = **$55,000**
- 非控制權益（15%）：157,500 − 1,000,000 × 15% = 157,500 − 150,000 = **$7,500**

✅ 驗算：55,000 + 7,500 = 62,500 ✓
📌 控制權益的商譽 55,000 ÷ 85% ≠ NCI 的 7,500 ÷ 15%：每 1% 分到的商譽不一樣，因為 NCI 公允價值不含「控制權溢價」。

## 常見錯誤 / 易混淆
- 用原始成本（$240,000）算商譽 ❌，要用收購日公允價值（$300,000）
- FVOCI 權益工具的累計 OCI 轉到**損益** ❌（只能轉保留盈餘）

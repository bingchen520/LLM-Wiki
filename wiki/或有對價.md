# 或有對價（Contingent Consideration）
> 「如果被收購公司明年賺到某個數字，我就再多付你一筆」：這種**看未來條件才決定要不要付**的對價，叫做或有對價。

## 定義
合併契約規定：若將來某些特定事項發生或條件成就，收購者有義務對賣方額外給付（現金、非現金資產或發行證券）；或收購者有權利收回先前已支付的部分對價。[Ch1 p.4]

## 重點

### 收購日的認列 [Ch1 p.4]
- 或有對價相關的權利與義務，屬於**移轉對價的一部分**，以**收購日公允價值**衡量
- 收購者**有義務**將來支付 → 分類為**負債或權益**
- 收購者**有權利**收回 → 分類為**資產**

### 後續處理 [Ch1 p.5]
| 分類 | 後續處理 |
|---|---|
| 權益 | **不得再衡量**，最後結清時在權益內轉列 |
| 資產或負債 | 每一報導日依公允價值**再衡量**，變動數認列為**當期損益** |

### 怎麼判斷是負債還是權益？（補充，依 IAS 32）
- 付**現金** → 負債
- 給「**價值固定**」的股票（股數會變）→ 負債
- 給「**股數固定**」的權益工具 → 權益

### 衡量期間內的新資訊 vs. 收購日後的事項
- 衡量期間內取得「收購日已存在之事實」的新資訊 → 追溯調整收購日公允價值（**調整商譽／投資**）[Ch1 p.4]
- 收購日後才發生的事（例如真的達成獲利目標）→ 依上表的後續處理（**不調整商譽**）[Ch1 p.5]

## 例題

### 【釋例】或有對價：巨歐公司收購奇歐公司 [Ch1 p.5–6]
**題目摘要**：巨歐 X3/12/31 付現 $11,650,000 收購奇歐 100% 股份。若奇歐 X4 年稅後淨利 ≥ $1,500,000，巨歐要額外支付：
(a) 現金 $150,000
(b) X4/12/31 價值相當於 $50,000 的巨歐普通股（面額 $10）
(c) 5,000 股巨歐不可贖回特別股（面額 $10，股利由巨歐裁量）

**考點**：三種或有對價的分類不同，後續處理也不同。

**步驟 1：分類**
| 項目 | 分類 | 理由 |
|---|---|---|
| (a) 現金 $150,000 | 負債 | 要付現金 |
| (b) 價值 $50,000 的普通股 | 負債 | 價值固定、股數不固定（補充：IAS 32） |
| (c) 5,000 股特別股 | 權益 | 股數固定、不可贖回、股利由公司裁量 |

**(1) X3/12/31 收購分錄**（收購日公允價值：a $60,000、b $20,000、c $120,000）
```
投資奇歐公司          11,850,000
    現金                       11,650,000
    或有對價負債                   80,000   ← 60,000 + 20,000
    資本公積－或有對價             120,000
```
✅ 驗算：11,650,000 + 80,000 + 120,000 = 11,850,000

**(2) X4/2/15：衡量期間調整**（重新評估收購日公允價值：a $67,500、b $22,500、c $135,000）
奇歐 X3 年的獲利是**收購日已存在的事實**，且在一年內取得資訊 → 追溯調整收購日金額。
- 負債：(67,500 + 22,500) − 80,000 = +10,000
- 權益：135,000 − 120,000 = +15,000
```
投資奇歐公司              25,000
    或有對價負債                   10,000
    資本公積－或有對價              15,000
```
✅ 已確認（使用者）：屬衡量期間調整。

**(3) X5/3/20：達成目標，結清**（X4/12/31 普通股市價 $25、特別股市價 $55）
- (a) 付現金 $150,000
- (b) 要發行 50,000 ÷ 25 = **2,000 股**普通股 → 股本 2,000 × 10 = 20,000，溢價 30,000
- 負債帳面 90,000，實際結清 200,000 → **損失 110,000**
```
或有對價負債              90,000
或有對價損失             110,000
    現金                          150,000
    普通股股本                     20,000
    資本公積－普通股溢價            30,000

資本公積－或有對價       135,000      ← 權益類不再衡量，用帳面金額轉列
    特別股股本                     50,000   ← 5,000 × 10
    資本公積－特別股溢價            85,000
```
✅ 驗算：第一筆借 200,000 = 貸 150,000 + 20,000 + 30,000；第二筆借 135,000 = 貸 50,000 + 85,000
📌 特別股市價 $55 是干擾數字：權益類或有對價不再衡量。
📌 提醒：負債類或有對價每一報導日都要再衡量；本題只問 X5/3/20 的分錄，所以一次認列差額。

## 常見錯誤 / 易混淆
- 把權益類的或有對價也拿來再衡量 ❌
- 把收購日後的事項（真的達成目標）拿去調整商譽 ❌

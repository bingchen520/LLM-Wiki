# 反向收購（Reverse Acquisition）
> 表面上是 A 公司發股票吸收合併 B 公司，但合併後 B 的老股東反而握有多數股權。會計上看實質，所以**真正的收購者是 B**。

## 定義
在某些企業合併中，發行權益證券之公司（**法律上收購者**）是**會計上被收購者**，而權益證券被他公司取得者（**法律上被收購者**）則為**會計上收購者**。[Ch1 p.3][Ch4 p.1]

## 重點

### 1. 辨認收購者 [Ch4 p.1]
以交換權益證券完成合併時，不能直接把發行股票的公司當成收購者，要考慮：相對表決權、相對多數的少數表決權、治理單位組成、高階管理階層組成、權益交換條件 → [[辨認收購者]]

### 2. 設算移轉對價 [Ch4 p.1]
假設「會計上收購者」發行股票去買「會計上被收購者」：要發行幾股，才能讓被收購者的股東擁有和反向收購後相同的持股比例？這些股票在收購日的公允價值就是移轉對價。

### 3. 商譽或廉價購買利益 [Ch4 p.1]
設算的移轉對價 − 會計上被收購者可辨認淨資產（通常為公允價值）→ 正數為商譽，負數為廉價購買利益

### 4. 合併後財務報表 [Ch4 p.2]
| 項目 | 怎麼列 |
|---|---|
| 報表名稱 | 用**法律上收購者**的名稱，附註說明內容延續法律上被收購者 |
| 資產負債 | 會計上收購者 → **帳面金額**；會計上被收購者 → **公允價值** |
| 權益總額 | 會計上收購者合併前權益 + 設算移轉對價 |
| 股本（金額） | 法律上收購者合併前股本 + 因合併發行股份的總面額 |
| 保留盈餘 | 會計上收購者合併前的保留盈餘 |
| 比較報表 | 會計上收購者的股數依換股比率追溯調整 |

### 5. 每股盈餘的分母 [Ch4 p.2]
- 期初到收購日前：**會計上收購者**的加權平均股數 × 換股比率
- 收購日到期末：**法律上收購者**實際的加權平均股數

## 例題（完整過程）

### 【例】甲公司吸收合併乙公司（判斷收購者）[Ch1 p.3]
合併前甲 100 股、乙 750 股。每 2.5 股乙股換 1 股甲新股 → 甲發行 300 股，合併後共 400 股：甲原股東 25%、乙原股東 **75%** → 乙是會計上收購者。

### 【釋例】吸收合併之反向收購：大大公司與小小公司 [Ch4 p.3–4]
**題目摘要**：大大 X1/12/31 以換發新股方式吸收合併小小，大大存續。換股比例：每 0.5 股小小股票換 1 股大大新股。小小市價每股 $120；大大沒有活絡市場，估計公允價值每股 $62。

| | 大大帳面 | 大大公允價值 | 小小帳面 | 小小公允價值 |
|---|---|---|---|---|
| 流動資產 | 60,000 | 70,000 | 250,000 | 235,000 |
| 非流動資產 | 120,000 | 100,000 | 150,000 | 200,000 |
| 流動負債 | 40,000 | 50,000 | 50,000 | 48,000 |
| 非流動負債 | 45,000 | 40,000 | 150,000 | 150,000 |
| 普通股股本（面額 $10） | 20,000 | | 40,000 | |
| 資本公積 | 35,000 | | 60,000 | |
| 保留盈餘 | 40,000 | | 100,000 | |

**考點**：判斷誰是會計上收購者、設算移轉對價、合併後報表的權益怎麼列。

**步驟 1：判斷收購者**
- 小小流通在外 40,000 ÷ 10 = 4,000 股 → 大大要發行 4,000 ÷ 0.5 = **8,000 股**
- 大大原有 20,000 ÷ 10 = 2,000 股 → 合併後共 10,000 股
- 小小原股東持股 8,000 ÷ 10,000 = **80%** → **小小是會計上收購者**

**步驟 2：設算移轉對價**
假設改由小小發行股票：要讓大大原股東擁有 20%，小小要發行 x 股
- 4,000 ÷ (4,000 + x) = 80% → x = **1,000 股**
- 移轉對價 = 1,000 × $120（小小的市價）= **$120,000**

📌 大大每股 $62 是干擾數字：小小有活絡市價，用小小的股價設算。

**步驟 3：商譽**
- 大大（會計上被收購者）可辨認淨資產公允價值 = 170,000 − 90,000 = 80,000
- 商譽 = 120,000 − 80,000 = **$40,000** ✓（與講義一致）

**步驟 4：以會計上收購者（小小）的帳為基礎的分錄**
```
① 資本科目調整（讓股本金額反映法律上大大的股數）
資本公積              40,000
    普通股股本                  40,000

② 收購分錄
投資大大公司         120,000
    普通股股本                  20,000
    資本公積                   100,000

流動資產              70,000
非流動資產           100,000
商譽                  40,000
    流動負債                    50,000
    非流動負債                  40,000
    投資大大公司               120,000
```

**步驟 5：合併後資產負債表**
| 資產 | 金額 | 負債與權益 | 金額 |
|---|---|---|---|
| 流動資產 | 250,000 + 70,000 = 320,000 | 流動負債 | 50,000 + 50,000 = 100,000 |
| 非流動資產 | 150,000 + 100,000 = 250,000 | 非流動負債 | 150,000 + 40,000 = 190,000 |
| 商譽 | 40,000 | 普通股股本 | 20,000 + 8,000 × 10 = **100,000** |
| | | 資本公積 | **120,000** |
| | | 保留盈餘 | **100,000**（小小的） |
| 合計 | **610,000** | 合計 | **610,000** |

✅ 驗算：
- 權益總額 = 小小合併前 200,000 + 設算對價 120,000 = 320,000；100,000 + 120,000 + 100,000 = 320,000 ✓
- 股本：小小 40,000 + ① 40,000 + ② 20,000 = 100,000 ✓；資本公積：60,000 − 40,000 + 100,000 = 120,000 ✓
- 資產 610,000 = 負債 290,000 + 權益 320,000 ✓（與講義一致）

## 其他例題（只列考點與答案）
| 例題 | 頁數 | 考點 | 答案 |
|---|---|---|---|
| 信誠公司 | Ch4 p.4 | 反向收購下的 EPS：收購日前用會計上收購者股數 × 換股比率 | 理義 45,000 × 2/3 = 30,000 股 × 9/12 + 50,000 股 × 3/12 = 35,000 股；EPS = 840,000 ÷ 35,000 = **$24**（與講義一致） |

## 常見錯誤 / 易混淆
- 「誰發行股票、誰存續，誰就是收購者」❌
- 合併後的保留盈餘用法律上收購者（大大）的 ❌ → 要用會計上收購者（小小）的
- 設算移轉對價時用法律上收購者的股價 ❌
- 📌 Ch1 的基本例題**不用**考慮反向收購，出錢的一方就是收購者（CLAUDE.md 規則 8）

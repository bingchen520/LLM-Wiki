# 高會 LLM Wiki：企業合併與合併財務報表

## 1. 主題與簡介
本專案以高等會計學「企業合併與合併財務報表」（上課講義 Ch1–Ch5）為主題，用「先討論、後生成」的方式建立一個 LLM Wiki，再以這個 Wiki 作為唯一的知識來源，製作一份給第一次接觸企業合併的人看的教學 HTML 簡報。

- **資料來源**：5 份上課講義（Ch1 企業合併導論、Ch2 母公司投資會計、Ch3 合併報表導論、Ch4 企業合併特殊議題、Ch5 合併工作底稿），清單見 [`raw/資料來源.md`](raw/資料來源.md)
- **Wiki**：18 頁概念、方法與特殊議題頁面，每頁標註講義來源頁數，例題附完整解題與驗算
- **簡報**：19 張，涵蓋 Ch1–Ch5，含工作底稿逐步動畫與小測驗
